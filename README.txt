APTITUDE PRACTICE EXAM WEBSITE

HOW TO RUN
1. Extract the ZIP into a folder.
2. Open index.html in a modern browser (Chrome, Edge, Firefox).
3. Select Set 1, Set 2, or Set 3 and begin.

EXAM DESIGN
- 3 fixed sets; 60 questions per set.
- 90-minute timer per attempt; auto-submit when the timer expires.
- 15 questions per topic in every set: Number System, HCF & LCM, Averages, Remainder Theorem.
- 180 distinct question texts across the three sets.
- Every question is a static object with keys: question, options, answer, set.
- answer is a zero-based index into options.
- No server or installation required.

FILES
index.html                 Website layout
style.css                  Styling
js/number-system.js        45 Number System questions
js/hcf-lcm.js              45 HCF & LCM questions
js/averages.js             45 Averages questions
js/remainder-theorem.js    45 Remainder Theorem questions
js/app.js                  Set selection, timer, answer selection, scoring and review

NOTE
Questions are original practice questions based on the concepts and patterns in the supplied PPTs, not copied verbatim. This is a local practice website; refreshing during an attempt resets that attempt. The timer runs while the page is open.
